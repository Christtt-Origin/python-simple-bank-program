# 🏦 Python Simple Banking Program

A beginner-friendly banking system built with Python using Object-Oriented Programming (OOP). This project was created to practice classes, objects, and basic banking operations.

## ✨ Features

- 👤 User Registration
- 🔐 User Login
- 💰 Deposit Money
- 💸 Withdraw Money
- 🔄 Transfer Money Between Accounts
- 📜 Transaction History
- 🆔 Automatic Account UID Generation
- 🔒 Hidden Password Input (`getpass`)

## 🛠️ Built With

- Python 3
- Object-Oriented Programming (OOP)
- Git
- GitHub

## 📂 Project Structure

```
Banking Program/
├── Main.py
├── Bank.py
├── Account.py
└── Function.py
```

## 🚀 How to Run

1. Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/python-simple-bank-program.git
```

2. Navigate to the project:

```bash
cd python-simple-bank-program
```

3. Run the program:

```bash
python "Banking Program/Main.py"
```
